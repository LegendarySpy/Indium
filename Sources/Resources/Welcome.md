# Welcome to Indium

Hey! This is a note. Every note in Indium is a plain Markdown file in a folder on your Mac, so nothing is locked in here. Edit this one, or delete it once you've had a look.

## The basics

- Just type. Markdown like **bold** or a `## heading` tidies itself up once your cursor moves away.
- It saves as you go, so there's no need to press `⌘S`.
- `⌘N` starts a new note, `⌘O` opens any note, and `⌃⌘S` shows your files.
- `⇧⌘N` makes a temporary note that's never saved unless you choose to keep it.

## A few nice things

- Type **/** for tables, headings, equations and more. Press Tab to accept.
- Math works like Obsidian, inline as $E = mc^2$ or on its own line:

$$
\frac{1}{2} + \frac{1}{4} = \frac{3}{4}
$$

- End a line with **=** (try `12 * 4 =`) and the answer shows up. Tab keeps it.
- Click a table to edit it like a spreadsheet. The layout button lets text wrap beside it.
- Drag or paste images straight in, and `⇧⌘E` exports a clean PDF.

## Your notes

This note lives in **Documents › Indium**. To use a different folder, like an existing Obsidian vault, choose **File › Open Folder…** (`⇧⌘O`).
